# Unit 4 Discussion: Binary Search Trees

## Overview

This assignment introduces Binary Search Trees (BSTs) and recursive tree operations.

## Learning Objectives

- Build a BST
- Insert values recursively
- Search recursively
- Perform in-order traversal
- Understand BST organization

## Requirements

1. Build a BST.
2. Insert multiple values.
3. Demonstrate in-order traversal.
4. Test searching.
5. Demonstrate edge cases.
6. Create a real-world BST example.

## Unit 4 Reflection

For this assignment, I learned how Binary Search Trees (BSTs) store and organize information. I used employee ID numbers as my example because a company could use them to find employee records. I learned that smaller numbers go to the left side of a node and larger numbers go to the right side.

The insertion and search methods were challenging at first because I had to understand how recursion worked. I reviewed the code and followed how each method moved through the tree. Once I understood the process, it became easier.

I also learned how in-order traversal worked. The program visited the left side first, then the current node, and finally the right side. This displayed the employee IDs in sorted order.

A balanced BST can search faster than a regular unsorted list because it does not need to check every value. However, I learned that inserting numbers in order can create an unbalanced tree. When this happens, searching can become slower.

I also tested empty trees, duplicate values, and a tree with only one node.
